# 钠衡真实 API 工作台

`npm run dev` 启动本地 Vite 5173，`/api` 代理到 127.0.0.1:8000。`npm run build` 使用 TypeScript 检查并输出 dist；后端会静态提供实际构建。

七页基于 API 保存结果，没有 mock 或随机兜底。用户从总览创建作业，改温度/电价创建新 RunID；缺结果显示未知，错误保留理由。回放创建显式 mode=replay 记录且不算独立样本。HTML 报告通过 `/api/reports` 索引受控工件。

`npm run test:e2e -- --grep smoke` 针对已启动真实前后端；通过页面提交作业、改变输入、读取后验与预测、检查报告字节和回放身份。不预置后端答案，不 mock API。浏览器依赖缺失属于受阻，不可跳过后宣称通过。

这里只交付 W01 首个闭环。W02 仍需完整生命周期、模组、校准、ICA/EIS、收益优化、主动学习、失配撤回、多作业批量与数据导入等后续真实能力。当前页面显示这些限制，不能视为完整产品验收。
