# 模型、化学形式化与 AI 发现规格

本文件把提案第2—4节转成实现任务。公式是待实现、待检查的研究模型与候选命题，不是关于实际钠电的已验证规律，也不是已经通过 Lean 的证明。

## A. 四种模型身份必须分开

1. **theory_fixture**：可控反应/位点模型族，用于命题、反例与算法回归。参数可人为设计，但要标 synthetic，不能称某厂商真实电芯。
2. **fast_operational**：用于后验、寿命和优化的快速模型。须有观测方程、单位、适用域和误差来源，可由参考模型/真实数据拟合。
3. **reference_sodium**：锁定钠电化学体系的较细电化学模型，供反例/复核与独立评价。采用什么参数、支持什么温区、是否包含副反应都逐项登记。
4. **public_data_case**：一套真实电芯与测试协议。与不相同化学体系的仿真只做方法迁移对照，不混为统一参数集。

同一个研究模型既是控制器又是评价环境仅用于代码单元测试；方法效果实验至少有参数和观测噪声失配，进一步保留结构失配测试。调用同一求解库不等于一定不独立，但必须解释共享假设和误差。

## B. 单位、符号和观测

内部秒、mol、K、A、V、Ω、W、J；显示层可用小时、℃、Ah、kWh。转换集中实现。电流 I>0 表示放电；所有外部数据必须附带原始符号和转换规则。实际化学量不能和无量纲 risk_score 混同。

化学核定义物种数量向量 n≥0、计量矩阵 S（行物种、列反应）、元素组成矩阵 E、电荷向量 z。对每个内部反应验证 E S=0 与 zᵀS=0；电子和外部储库必须显式计入，开放系统采用 n'=Sv+b 的端口收支。仅证明 E S=0 的线性恒等式不构成完整生命周期理论。

观测器可接收电压、电流、温度、测量时间与允许的诊断数据；可用动作历史同样合法。参考内部占据、真实参数、真实 SOH/RUL 只进入评估器。合成噪声、真实测量缺失和传感器偏差分别登记。ICA 需要足够单调、采样和低噪声条件；对不可用片段返回 reason，而非插出假峰。EIS 原始数据不可用则不伪造阻抗测量。

## C. 首批研究模型：可逆位点＋显式副反应

位点反应使用 Na⁺+e⁻+S_i ⇌ NaS_i；有效副反应必须完整列出消耗/生成物种。例如若用 NaS_i→S_i+P_i 表示不可逆俘获，则 P_i 在抽象模型中承接 Na 和相应电荷记账，并声明是有效产物类别，而不是冒充真实 SEI 成分。任何气体/结构副反应未显式建模时都不在证明覆盖内。

一个基础核为：

    x_i' = a_i(u,T)(1-x_i) - b_i(u,T)x_i - c_i(u,T,l)x_i
    y'   = Σ_i N_i c_i(u,T,l)x_i
    q    = Σ_i N_i x_i

其中 N_i>0，0≤x_i≤1，a_i,b_i,c_i≥0；y 是该副反应导致的累计俘获量。Na 总收支还包含储库或正极的反向变化。若 c_i 依赖膜厚 l，需要给出 l 与通量/物质量的关系。模型的观察电压和温度由单独声明的读出/热模块给出，不凭“化学方程”自动获得。

### 驱动方式是强制审计项

上述 u 在基础定理中可作为给定电化学驱动，**不是默认等同于 BMS 的电流命令**。电流控制适配时要解相应电流平衡，区分可逆和副反应电子通量，处理电容电流等声明的分量，保证外部 I 与物质通量一致。若研究电位驱动下的定理，要么独立建立电流闭环适用条件，要么标明只用于那一层的模型检查。

第一个可执行示范可采用已声明的单调有效速率和有界电位根求解；这只是 synthetic 通道，不是已标定 Butler–Volmer 模型。根不存在时返回 infeasible；禁止夹到端点再伪装为满足原电流。完整钠电通道通过经过审计的参考模型适配，不能把抽象位点参数硬塞进无映射的 DFN。

## D. 核心形式任务与文件

所有定理要保存非形式表述、精确 Lean 声明、条件、证明、相关文献与调用位置。初始目标是 `formal/Naheng/`，不能只构造一个 `theorem True` 再宣称化学库已完成。

### T0 / Chemistry：语义、收支与状态域

`Species.lean`、`Reaction.lean`、`Balance.lean`：有限物种/反应、计量、库存与电荷。由 E S=0 推出模型解的库存变化仅由 b 决定；存在 ODE 解及可微性是显式条件或已有定理的前提，不偷偷新增“守恒”假设。

`Sites.lean`：位点上下界的不变性，需声明速率正性、连续性/解存在等条件；仅证明在 x=0,1 处导数方向不能自动代替全轨迹不变性。先验证边界引理，再应用/证明不变性结论。

`Thermodynamics.lean`：在严格声明的等温、局部详细平衡与正通量条件下，从速率/势关系与链式法则推导耗散符号。开放端口额外记电功和物质输入；变温模型另行记能量和熵关系，禁止从封闭定理直接导出“充电自由能下降”。基础关系已有文献，作为形式化贡献而非自然规律发现。

### T1 / Reduction：精确聚合、不可充分性及近似

基础回归令 r_i=a_i+b_i+c_i，与 x 无关但可由同一个外部 u(t) 决定。若全部 r_i=r，则 q'=A-rq，A=ΣN_i a_i；这是 n 位点总量闭合的一条充分条件。

反例回归取 N_1=N_2=1、a_1=b_1=1、a_2=b_2=2、c_i=0；状态 (0.25,0.75) 与 (0.75,0.25) 的 q 均为1，但 q' 分别为 -0.5 和0.5。此处只是一对精确有理数示例，用来检验搜索器确实能反驳“总量无条件足够”，不得硬编码成唯一发现。

累计副反应也要保留时，q 闭合未必足够，因为 y'=ΣN_i c_i x_i 可能依赖内部组成。研究按 (r_i,c_i) 或更一般共享系数类聚合、线性输出保留及与观测的关系；这些与已有线性聚合/双模拟关联，必须查重。

`Residual.lean` 的基础近似候选：对 0≤x_i≤1 和选定 r̄，有

    |q'-(A-r̄q)| ≤ Σ_i N_i |r_i-r̄|.

这是待形式化的基础界，不假装是新定理。下一步研究能利用给定 q、参数结构和副反应约束的更紧界、足够状态以及时间范围，而不是仅复制这个松界。

`Trajectory.lean`：相同外部驱动、r̄≥r_min>0、初值误差 e0 及全时域残差界 ε 成立时，推导相应积分/指数误差包络。常数 r̄ 的候选形式是 e0 exp(-r̄t)+ε(1-exp(-r̄t))/r̄。变系数使用正确积分因子或以 r_min 建界，不能把变系数直接当常数。内部域保持是前提的一部分。

`Readouts.lean`：误差如何映射到指定可观测量与累计副反应；读出的 Lipschitz 常数或其他正则条件必须有来源/证书。任意神经网络误差不能由一行 `assume bound` 变成完整认证。

### T2 / Aging：机制→容量协议→条件寿命

以反应和扩散串联的声明模型为首个形式例，正参数 D,k,Ω,Δc 和膜厚 l≥0 满足

    l' = Ω Δc / (1/k + l/D).

推导积分关系 (l-l0)/k+(l²-l0²)/(2D)=ΩΔc t。经典线性/平方根极限用于回归，并研究近似有效域/误差；变温和竞争副反应单列条件，不能直接套常参数推导。模型系数来源与实际 Na 电芯的适用性独立验证。

`CapacityProtocol.lean` 及对应 Python 模块：可用容量是指定初始化、温度、倍率与截止条件下的积分，不把 q 当作容量；SOH 是同协议容量比。预测退役时间按协议阈值首次到达定义。若容量曲线在穿越区下降斜率有下界 s_min>0，才研究时间误差与容量误差的关系；其他情形返回上下夹逼/删失，不能给无条件 RUL 精确界。

### T3 / Contracts：化学误差进入运行

证明与实现 `|g-g_eff|≤e`、`g_eff+e≤0` 推出 `g≤0` 的合同；这本身只是标准引理，必须关联 T1/T2 推导出的具体 e 才能构成化学连接。

若事件 E 表示所有所需误差包络成立，且 P(Eᶜ)≤δ、V∩E⊆V_eff，则 P(V)≤P(V_eff)+δ。无须假设独立；但 δ 本身需要统计依据，且不可将后验分位区间自动当作全轨迹概率覆盖。实数证明与浮点判断之间还要保留数值容差/区间层；没有数值证明的部分注明测试支持。

### 审计与完成要求

`formal/Naheng/Exported.lean` 显式导出发布目标；审计枚举发布目标全部传递依赖，不只 grep 工作目录。默认 core 只接受 propext/Classical.choice/Quot.sound；sorryAx、自造结论公理和未审计本地公理拒绝，native evaluation 信任依赖单列，不默认为 kernel-only。

允许把尚未证明的命题放在 `research/candidates/*.json` 并保持状态 unknown，但不能通过 `axiom` 或 `sorry` 导入正式模型包。Lake 成功且有日志，声明哈希、工具链、依赖和使用域一致，才标 `checked`。官方说明支持该审计方向。[S3]

最终不仅要求 T0 小引理：需要 T1/T2/T3 有实际化学语义的连贯推导、适用条件、反例和运行调用，既有理论形式化与新候选的区别要在 NOVELTY.md 说明。

## E. AI 搜索的最小可执行设计

候选不是任意代码字符串，而是带类型 AST：有限状态分组、正参数关系、低阶表达式、限定域，以及待推导目标。设计语言包含语义/单位检查，拒绝无法求值或把目标抄成假设的候选。先限定这套语法完成实质链路，再扩展。

迭代为：语法生成候选→在训练模型族上检查/寻找反例→更新候选质量与成本代理→选择下一个候选或下一次证据查询→尝试证明→注册证据→独立任务族评估。概率模型可基于结构特征、经验残差、证明成本等构建，训练数据只来自允许的搜索集。`verified`、`counterexample_found`、`timeout_unknown`、`invalid_syntax` 的监督含义不同，不能把超时当假命题。

首个实际学习器可采用 GP/统计排序模型；它必须读入新反馈后改变策略，保留 checkpoint、训练数据和采集分数。随机/枚举/人工规则只是基线而非冒充学习模型。可选 LLM provider 只输出受限候选，需显式配置预算与用户同意，不读取凭据目录；外部网络禁用时本地闭环仍可运行。若要声称 LLM 辅助发现，必须有真实调用和独立核验证据。

打分同时考虑目标误差、适用域覆盖、模型复杂度、仿真/证明成本与运维价值。不能只按证明条数最大化，更不能缩小域到孤立点“取得成功”。各项权重固定于训练/验证协议，并用消融检验。新查询准则是研究候选，不先写成已有效算法。

## F. 应用模型与研究模型的验收边界

快速电学可先有独立实现的等效模型用于强基线和数据回放，但正式系统不能永远只调用 ECM，而理论核闲置。至少一条反应归约/寿命/误差路径通过 model package 实际进入快模型或风险计算；它在参考钠电/真实数据上的差异另外测量。

温度、循环、历时和功率影响退化需在方程里产生，不可直接按“循环编号”从预制 SOH 曲线读取。人为加速退化只用于短测试，数据属性 `accelerated_synthetic=true`，不用于真实寿命主张。电化学、热和副反应之间用同一物质/能量账检查重复损耗；实际输出不支持的事件保持未知。

`diagnose_model()` 应能区分数值求解失败、观测不足、参数超域、结构残差和输入不合法，分别发出错误/告警；不得所有异常都吞掉并返回默认安全策略。
