# 0002：冻结源码续算与有界验收批次

每个数值作业先复制当前真实源文件与依赖锁，记录逐文件哈希。取消、硬超时和写入失败保留不完整状态，不能提前发布成功。

完整同化边界保存不可覆盖的私有模拟器、传感器随机状态和观察器自身检查点，再原子发布公共检查点指针。恢复复制父运行的冻结源码，校验源、锁、输入和检查点字节，创建新 RunID；历史身份映射和继承账目单列。模拟器真值不进入观察器恢复输入或公共 API。部分模型域截止区间不能跳过剩余时间。

续算与重算是两个明确操作；旧运行缺少受支持检查点会拒绝续算。继承轨迹不增加独立试验计数。真实短运行的取消与续算对照覆盖初始、中间和最后积分边界，具体结果以日志为准。

S04 加入真实逐周期/宏映射对照、模组更换及容量截止求解后，17 项独立验收批次实测 156.73 秒。完整数值 pytest 批次上限从 180 调整为 600 秒，并加入原先遗漏的注册表 DSL 测试；单次仿真 worker 和证明仍保持 120 秒上限，整体批次未超过配置的 30 分钟预算。此调整不减少断言、误差条件或测试。
