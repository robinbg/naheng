# S04 模组和合成生命周期

此通道以未标定的两位点模型运行真实数值求解。它不是实际钠电寿命、退役时间或经济收益验证，也不提供严格全域误差证书。
M1 的运行服务、概率快照、容量协议和 `EnergyLedger` 不调用或接受本文件的宏跳步现金流；M1 继续完整数值积分。

## 4 串模组

`ModuleModel` 明确采用 4s，四个单体共享同一电流，端电压相加。
单体分别保留容量、速率、温度和约束参数；任一单体连续截止事件停止整组该动作。
邻接热传导在两个单体中采用相反热流，合计传导热为零。
热管理命令表示整组热流，平均分给四个单体；电耗按各单体声明的 COP 核算。
不把单体事件概率相乘，也没有在此生成模组事故概率。

## 实际宏循环推进

先执行三个完整周期，得到周期状态 `s1,s2,s3` 和每个充/放相位的求解能量。
当前固定策略的二阶周期映射为：

```text
d1 = s1-s0
d2 = s2-2*s1+s0
s(k) = s0 + k*d1 + k*(k-1)*d2/2
```

三阶有限差分乘组合系数与显式安全因子，形成**局部经验误差估计**。
状态的占据率、mol、K 分别有绝对误差预算；电能另设 J 预算。
预算累计，不能每跳自动清零来隐藏漂移；更换后只有新电芯状态预算重新开始，健康电芯的累计误差与累计能量误差继续保存。
周期及充/放相位端点还需满足占据、物质、温度、电位根和电压裕度。
接近容量退役阈值、容量未知、策略保持窗口不足或短尾段时采用精确单周期。
这里的裕度与有限采样不构成全相位连续安全证明；近似只属于合成预测通道。

策略回调返回 `CyclePolicy`，`hold_cycles` 明确授权保持多少周期。
默认为 1，不能假定动态策略在被跳过周期中保持不变。
回调在每个实际生命周期检查点得到当前协议 SOH、年龄、替换次数和数值误差估计，再返回新策略。
没有回调时采用固定合成周期策略，允许有界保持。

默认第一次跳步进行逐周期参考审计，之后定期再审计。
审计从已计算的前三周期继续，避免重复计算它们；审计能量只记录一次。
通过时运行状态实际采用宏映射，生命周期计数一次跨多个周期；未审计批次只执行校准周期，省去其余精细周期。
失败、超预算、越域或近退役时记录原候选和拒绝理由，采用首个已求解的精确周期继续。
`fine_cycles_avoided` 明确只计算没有进行精细求解的周期，不把审计周期计作加速。
是否节省时延仍须按同一任务实测，代码不预设性能或收益领先。

`cycle_jump_check` 保留为独立短逐周期误差探针；实际推进由 `run_lifecycle` 的跳步准入控制。
校准和审计的计算既不是额外运营动作，也不能重复计入售电。

## 容量、退役和维护

SOH 使用同一 `CapacityProtocol` 的真实截止放电积分之比，没有把储钠总量直接当容量。
协议初始化与 trapped→accessible 映射为明确的未标定合成假设。
缺少可计算协议容量时返回 unknown，不填零或无限寿命。
退役按照协议检查点首次达到阈值记录检测区间，不能把宽检查点区间伪装成精确连续 RUL。
退役记录保存单体出生时刻；更换重置该单体年龄，全球运行时钟继续。
更换分别登记丢弃与引入的 Na 库存端口，以及同一合成残值规则计算的回收现金与购置成本。
预算不足、求解/事件停止与右删失分别保留，不标记为完整寿命验证。

## 现金流与期末公平处理

`exact_phase_ledger` 保存精细积分相位的合成模型能量现金流。
`macro_projected_ledger` 单列宏跳步的预测能量、现金流和误差估计；不把它写入 M1 的 actual executed ledger。
购、售、热耗分别记账，不能把一个周期的净电能同时当售电和购电。
宏相位聚合记录周期数、周期长度和相位偏移，不伪造被跳过的逐周期观测。

期初和期末储能估值从当前状态做额外真实截止放电探针，**不重新充满电芯**。
探针是 counterfactual valuation，能量不进入运行售电收入。
比较值仅加期末减期初的储能估值，以及期末减期初的资产残值；维护购置/回收只入账一次。
无法完成探针时对应估值 unknown，不凭储钠总量或名义容量补齐。
电价、更换成本和残值函数来自 `LifecycleEconomics.source_id` 指定的 synthetic 会计规则，无实际市场或寿命收益主张。

## 验收入口

```text
uv run --frozen --offline --no-sync --extra dev --extra reference -m pytest tests/integration/test_module_topology.py tests/integration/test_lifecycle_feedback.py -q
```

覆盖同质能量/库存、异质单体限制、热耦合、实际跳步对完整逐周期轨迹、零误差预算回退、策略变化、协议未知、替换年龄和现金/期末估值分层。
实际执行日志、首次失败和恢复结果保存于 `artifacts/validation/S04-*`，结果以相应命令退出码为准。

`artifacts/lifecycle_validation/compare_cycle_maps.py` 保存同一 12 周期策略的完整精细/宏映射轨迹与实际差值。
`local_replacement_case.py` 保存显式加速老化、14 周期、专用 `1e-5 mol` 误差预算的局部更换回归。
该回归在 52 秒检测到第 1 个电芯退役并更换，保留其余电芯的宏映射误差；这是阈值检查点检测，不能解释为现实 RUL。
此前 12 周期未达到退役阈值的失败，以及更严格 `1e-7 mol` 专用预算拒绝所有候选的 24 周期结果，均保留原始日志。
这些不同输入对应不同验收目的；默认跳步预算未调整。局部更换案例只有一次完整参考审计跳步，没有未积分周期，因此本例不作加速主张。
