# F02 新候选的身份与已有理论对照

`ClassSufficiency.lean` 新增一般有限 n、正容量、整个物理占据立方体上的必要充分分类，证明组总量对真实总储钠导数和俘获速率充分，当且仅当同组的 `r=a+b+c` 与 `c` 分别相同。允许 `a` 在组内异质；四位点到两组的正速率例与总量不充分反例均实际 Lean 检查。它是模型内形式化贡献，未主张新的数学定理或钠电自然规律。

| 实际核读的原作者资料 | 对照及本候选边界 |
| --- | --- |
| [CLUE 原作者论文](https://arxiv.org/pdf/2004.11961)，v2，§2 Definition 1、约束输出定义、Jacobian 不变子空间描述及附录相关证明部分 | 原文的线性映射聚合与指定线性输出保留构成上位框架。本候选仅处理有限对角仿射位点族；把组容量加权总量写成矩阵行、把 `r` 写成对角矩阵，组内系数条件是该框架的特例。这一对应是本包的推导，不声称原论文出现完全相同的 Lean 命题。没有实现 CLUE 的最小维数搜索算法。 |
| [Approximate Constrained Lumping 原作者全文](https://arxiv.org/html/2411.14242v1)，Theorem 2.1、2.2 及近似误差讨论 | 原文描述因子分解、Jacobian 行空间判据与近似放宽。`GivenAmountResidual.lean` 是本声明模型上由三角不等式、已知 `q` 和容量加权系数均值推导的实数点残差；不等同于该文的矩阵容差算法，也不宣称已完成它的轨迹误差或新颖性比较。 |
| [Generic and critical parameters 原作者元数据/摘要](https://arxiv.org/abs/2606.28895)，v2 | 仅核读参数一般/特殊情形的研究范围；HTML v1 实际返回 Internal Error，未读全文，不能给逐定理比较或据此声称本候选具有新颖性。 |

`GivenAmountResidual.lean` 计算 `rbar=ΣN_i r_i/ΣN_i`，由定义证明系数偏差加权和为零，再导出 `|R|≤min(δq,δ(C−q))`，其中 `|r_i-rbar|≤δ`、`C=ΣN_i`。显式物理有理例达到新界 1/2，而原完整容量界是 2；更紧只指该例。一般参数下，两种预算没有无条件的大小顺序，使用时必须按同一状态和参数分别比较。候选新增了利用给定总量的推导，但没有通过穷尽文献确认其数学新颖性。

`CurrentClassBridge.lean` 把共享 `k/bias/c` 的组状态连接到实际指数电流平衡。它单独记录编译结果，不借用前两文件的成功。共同温度因子、参数、电流、物理域以及真实精确根是明确条件；Float/Brent 的容差不是精确根证书。所有失败与 UNKNOWN 保留。

只保留明确证明的输出。累计俘获量还必须携带其初值；电压/热量、可用容量、RUL、数值求解误差、现实安全、研究创新和运行时状态替代分别有自己的适用性与验收。不能从瞬时系数在一个时点相等推断整个驱动域都可合并。

本包不改原 F02 字段，也不把后续 P03 的运行连接、T3 或完整科学/GUI 闸门倒置为 F02 新前置。正式 `naheng formal check --suite reduction` 仍须由集成负责人接入后真实验收。

# 理论成果身份与创新性边界



当前九套局部形式发布共82个唯一目标，已有真实构建及逐声明传递公理审计：化学收支/库存17、精确聚合与反例7、瞬时残差7、常系数轨迹8、膜积分5、容量端点及条件阈值根14、变系数轨迹8、固定电流读出8、异质双位点组成与显式轨迹反例8。当前真实九套批次汇总见 `artifacts/formal/current-heterogeneous-partials-7f00a1d9/manifest.json`，退出0、328.268秒；每条Lean命令仍受原120秒界限制。新增exports后原八套实际重新构建审计并核对文件身份，化学收支与瞬时残差指针已重新绑定。完整core与严格现实安全仍未完成；原74及66汇总和所有首次失败/UNKNOWN保留。



这些结果是既有数学结构在已声明合成模型上的形式化和工程连接，尚未建立新的钠电自然规律。瞬时残差预算已用于每个表示后验样本的实际速率计算和动作准入；它不授权未来单状态替代、严格安全或现实收益。有效俘获产物不是已辨识的 SEI 成分。存在性、数值误差、全时域参数预算、实际闭环驱动与读出适用性仍分别验收。



共享系数类聚合与线性输出保留属于精确/受约束 lumping 的既有研究问题。原作者论文 [Approximate Constrained Lumping of Chemical Reaction Networks](https://arxiv.org/abs/2411.14242) 讨论保留用户指定输出的精确线性聚合及其近似放宽；“总量闭合”不自动保留电压、温度或俘获输出。2026 年预印本 [Lumping of reaction networks: Generic and critical parameters](https://arxiv.org/abs/2606.28895) 区分一般与特殊参数下的聚合。本轮仅核读原作者摘要/元数据，尚未完成逐定理全文比对，不能声称新颖性或领域空白。



原作者综述 [Constructive Methods of Invariant Manifolds for Kinetic Problems](https://arxiv.org/abs/cond-mat/0311017) 将约化描述作为不变流形问题，并讨论模型动力学与低维描述的一致性。这是检查闭环驱动、状态选取和适用域的背景，不是本项目反馈等价性的证明。



常参数膜 ODE 积分属于反应/扩散串联声明模型的基础数学；变温、竞争副反应与实际 Na 电芯系数不能由该积分直接认证。正斜率与有限阈值根条件引理不自动提供首次退役见证。膜生长文献全文对照尚未完成，本轮 DOI 网页被 robots 拒绝的记录不算已读全文。
