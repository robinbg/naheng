# 联合高斯未来传感器观察器

`src/naheng/estimation/joint_gaussian_observer.py` 新增显式 `JointGaussianObserver`。它从已验证校准候选保留同一组位点、库存、温度、反应速率与副反应速率样本及权重；采用时可以显式变更RunID，保留原时间与物理参数身份。原ParticleFilter和builtin观察器字节保持，其原来的对角零偏置拒绝规则保持。

每次未来观测前，实际按已执行电流、持续时间、环境温度和热命令传播全部表示出的行，包括零权重行。输入只含观测与执行条件，没有评估真值接口。若任何行提前终止、有物理事件、超域或预算不足，保留原观察器；只有全行完成才能提交新快照。单步上限3600秒、样本行上限256、内部100秒软预算，调用者必须使用120秒自有进程树硬预算。

似然的通道和单位固定为 `(voltage_V, temperature_K)` / `(V,K)`。创新为 `sensor−prediction−bias`，完整正定协方差通过Cholesky白化，权重按真实前次权重乘联合高斯似然更新。零先验权重保持精确零；没有重采样、虚构过程噪声或把温度读数写入潜在状态。均值、分位数、SOC和ESS来自同一联合样本。有限噪声读数可以超出潜在物理状态范围，须明确标记；每个实际预测状态仍须满足模型域。低ESS与未验证运营覆盖保持可见。

公共入口 `naheng joint-scenario-calibration --calibration-dir 当前包 --out 新目录` 对校准包重新验证来源、实际父轨迹、观测前缀、参数与源码。全部受保护包及来源字节在执行边界和提交前重新核对。内部世界只在首次规划后抽取；传感器误差按 `bias+Cholesky(Σ)z` 生成，控制器只收到V/I/T/time和后验。真实积分后立刻保存账本和评估轨迹，再更新传感器；未来计划与终端价值不记为实际现金。

实际样例在 `artifacts/joint_scenario_calibration/public-current-20261014-a`，新校准在 `artifacts/calibration/joint-current-20261014-a`。声明标准差为0.025V与0.25K、相关系数0.35，偏置为0.008V与0.06K，来源为明确的合成combined-error假设。两次5秒真实动作、两次未来联合更新和重规划完成；公共CLI收据 `artifacts/validation/E02-current-final-real-correlated-biased-sensor-replanning-entry-e57e10fb/command.json` 实际0、6.634秒。每次八行都实际传播；这些行、两次观测或反复重跑均不增加独立运营轨迹数，现实运营独立轨迹仍为0。

首源方法复核28/32退出1保留；修正有限预算与读数/状态语义后35/35退出0，范围仅源码与方法。首次真实公共入口暴露注册表与校准模块使用不同JSON哈希格式，新观察器误用了紧凑格式。修复仅让物理参数SHA采用既有registry序列化，状态/噪声/快照仍保留原紧凑算法；原新测试方法AST未改。83通过/1失败及参数错误输出保留在 `artifacts/progress/joint-first-entry-failure-63b14c04`。随后同组84通过、两个实际注册描述与旧紧凑哈希拒绝回归通过；独立17项修复复核也通过。另一次未加引号的pytest路径退出4、未运行测试，同样保留真实收据。
